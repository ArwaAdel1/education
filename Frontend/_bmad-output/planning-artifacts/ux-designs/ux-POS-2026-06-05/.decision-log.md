# Decision Log — Teacher AI Academy UX

## 2026-06-05

| # | Decision | Rationale | Source |
|---|---|---|---|
| UX-1 | Landing page is teacher-branded (photo, name, subject) | Builds trust; feels like the teacher's own site, not a generic platform | User |
| UX-2 | Signup fields: Full name, Phone (primary ID), Email, Password | Phone is the main identifier for Egyptian users, not email | User |
| UX-3 | Signup then pay (not pay then signup) | Account created first, then redirected to enrollment | User |
| UX-4 | Login: Phone + Password only. No social login | MVP simplicity; social login deferred | User |
| UX-5 | Password reset via OTP to phone, not email | Phone is primary identifier | User |
| UX-6 | Student Dashboard: two tabs — "My Courses" / "All Content" | Separate purchased vs. browse modes | PRD → User confirmed |
| UX-7 | Lesson view: YouTube embed + PDF download buttons | Simple content delivery model | PRD |
| UX-8 | Quiz taking: MCQ / T/F / Essay rendered inline | Three question types supported | User |
| UX-9 | Quiz results: score card + question review with correct/wrong highlighting | Immediate feedback for auto-graded questions | User |
| UX-10 | AI Tutor: chat bubble UI with citation chips | References specific lesson materials | PRD |
| UX-11 | Daily query counter visible in AI Tutor | Cost control transparency | User |
| UX-12 | Payment screen: two cards — Paymob and Promo Code | Dual enrollment paths presented equally | User |
| UX-13 | Teacher Dashboard: sidebar navigation + stats cards | Desktop-first, power-user interface | User |
| UX-14 | Content Manager: tree panel + editor panel | Split-panel layout for efficient content management | User |
| UX-15 | AI Quiz Generator: 3-step wizard (Prompt → Review → Publish) | Teacher-in-the-loop design | User |
| UX-16 | Student Engagement: table with expandable per-lesson rows | Teacher drills from student-level to lesson-level | User |
| UX-17 | Promo Code Generator: simple form, no chapter selector | Universal codes, student chooses when redeeming | User revision |
| UX-18 | Teacher screens are desktop-first; student screens are mobile-first | Different usage contexts (teacher at desk, student on phone) | Inferred from PRD, confirmed |
| UX-19 | Color theme: Deep Purple (#1A103D) + Cyan (#00C9DB) + accent purple (#7C3AED) | Modern, bold, distinctive. Stands out from traditional blue edtech | User selection from 3 themes |
| UX-20 | Typography: Cairo (Google Fonts) | Arabic legibility, modern, clean | User preference |
